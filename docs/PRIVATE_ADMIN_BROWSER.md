# Private Administrator Web Browser

## Access

The web browser is **for the site's administrators only**. It is not a general public visitor feature.

Public visitors should not be told that they have access to the private browser.

## Intended behavior

The administrator browser is intended to make ordinary web navigation convenient:

- Type **Walmart** → open Walmart
- Type **YouTube** → open YouTube
- Type **Toys R Us** → open Toys R Us
- Enter a full URL/domain → attempt the site directly
- Enter an unusual domain → attempt the domain directly
- Enter an ordinary phrase → use a search
- Typing can provide live search suggestions where the browser/device permits it

## Safety behavior

Normal searches use SafeSearch. Clearly identified X-rated search terms are blocked by the site's safety filter.

The browser opens external sites separately when a site does not allow embedded playback or browsing.

## Important limitation

A client-side keyword filter cannot truthfully guarantee that every possible adult website on the entire Internet will be identified. A stronger future implementation would use server-side URL/domain classification or another controlled browsing layer if the project requires a literal universal block.

## Product rule

This browser is an **administrator tool**, not a public website feature.
