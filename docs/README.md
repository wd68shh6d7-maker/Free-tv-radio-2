# Free TV & Radio — Guides & Project Records

This folder is the written record for the Free TV & Radio project. It keeps the public-facing explanations and the project decisions in one place so they can be reviewed later without relying on memory or chat history.

## What this folder covers

- Rooms and permissions
- Safety and moderation principles
- Nora, the planned website assistant
- The private administrator web browser
- Live TV and Radio guidance
- Announcements and the site's continuing-development notice
- Partnership and permissions planning
- Product principles and records

## Public vs. administrator-only

**Public:** Live TV, Radio, Apps, YouTube, Paid TV, Weather, Favorites, Stories, Invite, Announcements, and future public Rooms/Nora features.

**Administrator-only:** the Private Web Browser and other administrative controls.

## Project status

Free TV & Radio is an active project. Some features are complete, some are being polished, and some—especially Rooms and Nora—are planned or under development. Public descriptions should not imply that an unfinished feature is already fully available.

## Record-keeping principle

When a significant product decision is made, add or update a document in this folder. The website's Announcements/Guides area can then present a plain-language version for visitors while this folder preserves the fuller project record.
