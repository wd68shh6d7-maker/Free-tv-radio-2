# Product Principles & Records

## Free TV & Radio

The project aims to keep the main experience simple: free television, radio, useful apps, helpful guidance, and community features in one place.

## Live TV

Live TV uses the Famelack U.S. lineup as the guide structure. Provider services such as Pluto, Tubi, Sling, Plex, and Roku remain separate under Apps rather than being mixed into the Live TV lineup.

The guide should keep the player persistent while the user scrolls and should never invent program information.

## Radio

Radio remains separate from Live TV. Station playback, searching, regional browsing, and Favorites should remain understandable and touch-friendly.

## Favorites

TV and Radio Favorites are separate and may be saved locally for anonymous visitors or synchronized for authenticated users.

## Announcements and guides

Visitors should have a friendly place to understand the site, read project announcements, and learn how features work. A fuller written record is kept in this docs folder.

## Development notice

The project is still being built and refined. Some features are complete, while others are undergoing testing, safety review, or polish. Visitors should be encouraged to be patient as improvements continue.

## Partnerships and permissions

Any future integration involving outside services, programming rights, rooms, or permissions should use explicit authorization from the relevant rights holder or service. Partnership discussions and permissions should be documented before representing an integration as authorized.

## Administrator ownership

The website has one owner/administrator. Administrative tools should remain protected by authentication and should not be exposed as ordinary public features.
