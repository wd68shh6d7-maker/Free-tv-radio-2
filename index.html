🧪 Pre-test readiness

The core Lounge 2 shell, viewer close control, PiP/floating player, TV categories, radio navigation, apps, favorites, and Admin controls are included in this checkpoint.

✓ Viewer ×✓ PiP / floating player✓ TV categories✓ Radio country/state tabs✓ Apps✓ Favorites✓ Admin

Third-party sites can still refuse iframe embedding; Lounge 2 does not pretend otherwise.

This build has no rooms, game room, chess room, 3D room, reading room, Hoopla, Open Library, paid TV, California’s Gold, Max Velocity, Vercel, Supabase, Cloudflare, or GitHub dependency.

Some third-party services may refuse to display inside an iframe. When that happens, Lounge 2 shows a clear notice rather than pretending the service is embedded.

Browser safety

The lounge browser layer blocks known adult-search terms, suspicious schemes, common malware-download patterns and obvious popup/escape patterns. It cannot guarantee detection of every malicious site.

Allowed content rating: G, PG, PG-13, R, NC-17 and Not Rated. Allowed platforms: ordinary web sites including X/Twitter, subject to the safety filter.
